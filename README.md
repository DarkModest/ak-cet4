# AK-CET4（v1.3.1）

纯前端单文件的 CET-4 全真模拟考试系统。无需安装、无需后端：下载一个 HTML 文件，浏览器打开即可完整模拟大学英语四级考试流程。PDF.js、docx、worker 和中文字体 CMap 已全部内联，本地 PDF 解析离线可用。

## 功能

- 📄 **真题 PDF 本地解析** — 拖入真题 PDF，自动划分写作 / 听力 / 阅读 / 翻译四部分并抓取参考答案
- ⏱ **全真计时** — 写作 30min → 听力 25min → 阅读 40min → 翻译 30min，自动切节、到时自动交卷
- 🎧 **听力音频** — 支持本地音频文件，或直接使用内置 B 站真题合集分 P
- 🧩 **段落匹配** — 选中题干后直接点左侧原文段落完成匹配；允许同一段落重复选择，自动跳到下一条未答题干，支持 A–P 字母键、进度和清除全部
- 💾 **断点续考** — 考到一半刷新或关闭页面，进度自动保存在本机；下次打开时询问是否一键恢复（含听力音频）
- 📊 **本地评分** — 客观题自动判分，写作 / 翻译做基础语法检测与字数估算，按 710 分制生成成绩单
- 📤 **报告导出** — Markdown / DOCX 两份答题报告，可直接发给 AI 助手做深度分析
- 🌙 深色模式 · 提取内容可编辑 · 键盘快捷键（Ctrl+1~4 切换页面）

## 使用方法

1. 打开在线版：<https://darkmodest.github.io/ak-cet4/ak-cet4.html>（或下载 [`ak-cet4.html`](ak-cet4.html) 后用 Chrome / Edge 等现代浏览器本地打开）
2. **Step 1**：上传一份四级真题 PDF（纯本地解析，文件不会离开你的电脑）
3. **Step 2**：核对自动提取的题目与答案，可点击文字直接修正
4. **Step 3**（可选）：选择本地听力音频文件，或从 B 站真题合集里选对应试卷分 P；跳过则自动省去听力部分
5. 点击「开始考试」，按各节倒计时作答；交卷后查看成绩单并导出报告

> 中途有事离开？直接刷新或关闭页面即可，下次打开会自动询问是否恢复上次考试进度。
