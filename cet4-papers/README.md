# CET-4 真题 PDF（可搜索版）

这是从 [0609x/CET46-Resources](https://github.com/0609x/CET46-Resources) 的 `四级真题/*/真题PDF/`
整理出的可搜索 PDF 集合，供 AK-CET4 直接导入、自动分区。

## 内容

- 共 **92 份** PDF，保持原仓库的 `四级真题/<场次>/真题PDF/<原名>.pdf` 目录结构。
- **60 份原本就有文字层**：原样复制。
- **29 份纯图片扫描件**：离线 OCR 后生成“原页面图片 + 不可见文字层”的 PDF；页面外观不变，文字可复制、可搜索、可被 PDF.js 提取。
- **2023.06 的 3 份中文命名 PDF**：原文字层是 OCR 结果，存在段落 I 丢失、`22.6% farmers` 被识别成 `22.6armers` 等问题；这份集合用页面图像重新 OCR，修正了这些缺陷。
- 共 32 份经过离线 OCR（29 份扫描件 + 3 份需要重做的 2023.06 文本层），60 份保留原文字层。
- 每份文件的来源/处理方式/页数/文字字符数/格式见 [`manifest.json`](manifest.json)。

## OCR 方法

- 英文：Tesseract 5.5（`eng`，PSM 6，300 DPI）。
- 中文/中英混排：RapidOCR（PP-OCR，中文模型），按行坐标合并到英文文本层。
- 原页面图像以 300 DPI 保留；文字层使用不可见渲染模式（`render_mode=3`），不影响阅读。
- 未在 `ak-cet4.html` 中加入任何 OCR 代码；HTML 仍然只依赖 PDF.js 的普通文字层。

## 注意

- 2014–2015 的真题使用旧版题型编号（听力 1–25 + Section C 听写 26–35，阅读完形 36–45、匹配 46–55、仔细阅读 56–65）。这些 PDF 的文字层是完整的，但 AK-CET4 当前按 2016 年后的 `26–35 / 36–45 / 46–55` 结构解析，导入旧卷时可能需要人工核对。
- OCR 文本可能有少量字符级误识别；`manifest.json` 保留了每份文件的页数和来源，便于核对。
